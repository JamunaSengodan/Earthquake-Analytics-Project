# 🌍 Global Earthquake Analytics Project

## Project Overview
This project analyzes global earthquake data from 2021 to 2025 using Python, SQL and Streamlit.

The objective is to identify earthquake patterns, magnitude distribution, depth variations, yearly trends, geographical distribution and tsunami-related events.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
- SQL

## Dataset
- Source: USGS Earthquake API
- Period: 2021–2025
- Dataset: Cleaned earthquake records
- Features: Magnitude, depth, latitude, longitude, tsunami, time and other earthquake attributes.

## Project Activities
1. Data collection using USGS API.
2. Data cleaning and preprocessing.
3. Exploratory Data Analysis.
4. Feature engineering.
5. Data visualization.
6. SQL-based earthquake analysis.
7. Interactive Streamlit dashboard development.

## Dashboard Features
- Dataset overview
- Earthquake KPI metrics
- Interactive year, magnitude and depth filters
- Magnitude distribution
- Depth distribution
- Year-wise earthquake trends
- Global earthquake geographical map
- Tsunami analysis
- Automated business insights

## How to Run the Dashboard

Install dependencies:

`pip install -r requirements.txt`

Run the application:

`python -m streamlit run earthquake.py`

## Expected Outcome
An interactive dashboard that helps users explore global earthquake patterns and understand seismic activity through data-driven insights.
